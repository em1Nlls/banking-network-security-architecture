# BANKLAB — Project Scope & Requirements

**Project ID:** BANKLAB-001  
**Version:** 0.1  
**Status:** Draft  
**Project Type:** Enterprise Banking Network & Cybersecurity Architecture

## 1. Project Overview

BANKLAB is an independent engineering laboratory project focused on the design, implementation, integration, validation, and documentation of a fictional banking IT infrastructure in Türkiye.

The project covers enterprise networking, cybersecurity architecture, virtualization, identity management, application infrastructure, security operations, and infrastructure monitoring.

## 2. Project Objectives

- Design a secure, segmented, multi-site banking network.
- Implement Cisco-based enterprise switching and routing.
- Deploy Fortinet FortiGate network security controls.
- Establish centralized identity and directory services.
- Integrate network access control and privileged access management.
- Implement centralized security monitoring and log analysis.
- Develop a simulated banking application environment.
- Apply relevant Turkish banking regulations and established security architecture practices.
- Produce professional architecture, configuration, and validation documentation.

## 3. Proposed Infrastructure Scope

The initial architecture will cover:

- Headquarters and central IT management
- Primary data center
- Banking branch infrastructure
- Secure WAN connectivity
- Central identity and authentication services
- Segmented application and database environments
- Security monitoring and management services
- Remote administrative and employee access

The number of locations, network segments, and supporting systems will be finalized during architecture design.

## 4. Technology Scope

Planned technologies include Cisco IOS/IOS XE, FortiGate, VMware ESXi, Active Directory, PacketFence, JumpServer, Wazuh, Splunk, Zabbix, Grafana, Linux, and relevant infrastructure automation tools.

Technology selection and deployment remain subject to technical requirements, resource availability, and applicable licensing terms.

## 5. Regulatory and Technical References

The architecture will be informed by relevant publicly available sources, including:

- Banking Regulation and Supervision Agency (BDDK) regulations
- Turkish Personal Data Protection Law (KVKK)
- Applicable PCI Security Standards
- NIST cybersecurity publications
- Cisco Validated Designs
- Official vendor technical documentation

Each requirement will be assessed for applicability and mapped to relevant technical controls and validation evidence.

## 6. Project Deliverables

- Project Requirements Specification
- Regulatory Control Matrix
- High-Level Design (HLD)
- Low-Level Design (LLD)
- IP Addressing and VLAN Plan
- Security Policy Matrix
- Architecture Decision Records (ADR)
- Implementation Configurations
- Validation and Acceptance Test Reports
- As-Built Architecture Documentation

## 7. Project Limitations

BANKLAB represents a fictional banking environment.

All accounts, transactions, application data, and infrastructure are simulated.

The project does not claim production readiness, official regulatory compliance, or independent security certification.
